❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "Detect BPM button doesn't appear"
  → Make sure to select a song first
  → Check browser console (Cmd+Option+I) for errors

Problem: "BPM detection takes too long"
  → First run loads libraries (3-5s is normal)
  → Subsequent runs are faster (1-3s)

Problem: "Returns 0 BPM or very low confidence"
  → Audio file might be noisy or unusual tempo
  → Try a different song to test

Problem: "ModuleNotFoundError: librosa"
  → Run: pip install librosa
  → Or: pip install -r requirements.txt (if exists)

For more help:
  → Check: docs/BPM_DETECTOR.md
  → See console output: Cmd+Option+I in app
  → Check Python logs in: /output/ directory
